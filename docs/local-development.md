# Локальная версия YaMusic Downloader PRO

## Запуск на macOS

Понадобятся Node.js 24+, pnpm, Python 3 и FFmpeg с ffprobe.

```sh
pnpm install --frozen-lockfile
python3 -m venv .local/venv
.local/venv/bin/pip install -r server/requirements.txt
pnpm configure
```

Укажите `GETSONG_API_KEY` в `.env.local`. Команда `pnpm configure` создаёт отдельный `SERVICE_TOKEN`.
Она сохраняет уже заданный токен. Не отправляйте этот файл в Git.

```sh
pnpm build:extension
pnpm start
```

Сервер слушает только `127.0.0.1:8789`. Кэш находится в `server/data/cache.sqlite`.
Аудиофайлы сервера временные. Завершённые задания удаляются через час.

## Установка расширения

1. Откройте `chrome://extensions`.
2. Отключите другую версию YaMusic Downloader PRO, чтобы кнопки не дублировались.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение».
5. Выберите `.local/extension` внутри проекта. Используйте Cmd+Shift+G для ввода скрытого пути.
6. Обновите вкладки Яндекс Музыки, SoundCloud и VK.

Загружайте именно `.local/extension`. Эта папка содержит только файлы расширения и локальный токен сервера.
Ключ GetSongBPM, сервер, исходная коллекция и `.env.local` туда не попадают.
После изменений выполните `pnpm build:extension`. Затем нажмите «Обновить» у расширения и обновите страницы сервисов.

## Использование

- Рядом с треком Яндекса находятся числовой темп, цветной Camelot key и кнопка «Версии».
- Плашки используют непрозрачный фон и тёмный текст. Цвет тональности соответствует сектору круга Camelot.
- Кнопка «Версии трека» в popup открывает окно для текущего трека.
- Поиск использует Яндекс Музыку, VK и SoundCloud. Можно указать remix, edit, bootleg или mashup.
- Выберите источники флажками. VK включается отдельно после открытия его вкладки.
- Фильтр «Скрыть другие песни» убирает результаты без слов из названия исходного трека.
- Поиск показывает до 30 совпадений Яндекса/VK и до 20 SoundCloud. Уточняйте запрос для других результатов.
- Кнопка «Анализировать» сначала проверяет сохранённый результат. При его отсутствии запускается анализ фрагмента.
- После получения анализа кнопка «Пересчитать» позволяет принудительно обновить результат.
- Для VK автоматический показ BPM/key отключён. Сохранённый анализ доступен по кнопке.
- На страницах SoundCloud и в списках треков доступны кнопки «Скачать» и «Анализировать».
- В новом интерфейсе SoundCloud кнопки текущей страницы могут находиться в отдельной панели над плеером.
- В списках VK эти кнопки появляются у строк с доступными данными трека (`data-audio`).
- Обе кнопки используют общий сервер, кэш и выбранную папку. Автоматический анализ не запускается.
- Кнопка «Папка» открывает общий центр загрузок. Выберите каталог и разрешите запись.
- Оставьте центр загрузок открытым до конца очереди.
- Новая папка применяется только к новым заданиям. «Повторить» сохраняет исходную папку задания.
- Если Chrome потерял доступ, нажмите «Повторить» и разрешите доступ именно к папке задания.
- Для обычных загрузок Chrome доступен режим с подпапкой `1_Music`.

Имена остаются прежними: `Исполнитель - Название (версия).mp3`.
Совпадения получают суффикс `(1)`, `(2)` и далее. Данные BPM/key не добавляются к имени.

## Источники и точность

GetSongBPM используется для Яндекса. Сопоставление проверяет полное название с версией и исполнителя.
При наличии совпадения альбома оно имеет приоритет. Расхождение изданий на 1 BPM отображается диапазоном.
При разных тональностях или большем расхождении каталог не подставляет результат.
Анализ хранится отдельно от каталога. При расхождении интерфейс показывает оба результата и отметку «проверить».
SQLite хранит анализ бессрочно. Кнопка «Пересчитать» заменяет результат новым анализом.
При запуске сервер снимает срок хранения с ранее сохранённых анализов, включая записи с истёкшим сроком.
Положительный ответ каталога хранится 30 дней. Отсутствие записи в каталоге хранится сутки.
Кэш сохраняется после перезапуска сервера. Повторное открытие анализа не требует скачивания аудио.

Модальное окно изолирует `keydown`, `keypress` и `keyup` от хоткеев страницы.
Перехват запускается на `document_start`, раньше скриптов Яндекса. Нативный ввод текста и отправка формы через Enter сохраняются.
После обновления расширения обязательно перезагрузите страницу Яндекс Музыки, чтобы установить ранний обработчик.

Essentia анализирует 40 секунд моно PCM, 44,1 кГц. При слабом результате и достаточной длине берётся второй фрагмент.
Оценки уверенности Essentia не являются вероятностями. Интерфейс помечает анализ знаком `≈`.
BPM может отличаться вдвое. Короткий фрагмент может не отражать смену темпа или тональности.

Для MP3 сервер запрашивает HTTP Range. Для HLS он выбирает сегменты.
Если источник игнорирует Range, сервер может загрузить весь файл. Результат сообщает фактический объём.
HLS с MPEG-TS/MP3 и AES-128 поддерживается. HLS с EXT-X-MAP, BYTERANGE или SAMPLE-AES пока не поддерживается.

SoundCloud работает через yt-dlp и curl-cffi. Сервер использует публичные треки без браузерных cookies.
Вход в SoundCloud в Chrome не передаёт авторизацию серверу. Закрытые и платные записи могут быть недоступны.
Треки с DRM не скачиваются и не анализируются. Для MP3 сохраняется исходный аудиопоток.
Другие доступные форматы FFmpeg переводит в MP3. Перекодирование не повышает качество источника.

VK использует веб-сессию открытой вкладки. Адаптер основан на протоколе python273/vk_api.
Cookies и пароль не отправляются на сервер. Сервер получает только временный адрес выбранного аудио.
Неофициальный веб-API может измениться. Сессионную проверку VK нужно выполнить вручную.
Если новая версия страницы VK не содержит `data-audio`, кнопки не появятся. Для такого интерфейса потребуется другой адаптер.

## Проверки

```sh
pnpm check
pnpm test
```

Проверьте в Chrome:

1. Откройте коллекцию. Убедитесь, что BPM/key соответствует строке при прокрутке.
2. Откройте «Версии». Проверьте отдельные результаты и ошибки каждого источника.
3. Запустите анализ доступного трека. Сверьте показанный объём аудио.
4. Выберите папку A. Поставьте трек в очередь. Выберите папку B и поставьте второй трек.
5. Убедитесь, что первый файл находится в A, а второй — в B.
6. Скачайте тот же трек повторно. Убедитесь, что существующий файл не изменился.
7. Закройте центр загрузок во время задания. После открытия повторите его вручную и проверьте папку.
8. Откройте публичный трек SoundCloud. Нажмите «Анализировать», затем «Скачать». Проверьте результат и выбранную папку.
9. Повторите проверку в списках SoundCloud и VK. Прокрутите список и проверьте соответствие кнопки нужному треку.
10. Откройте анализ повторно. Проверьте отметку «Из кэша». Нажмите «Пересчитать» для нового анализа.

Основной сервис не развёрнут на внешнем сервере. Опубликована только страница backlink.
